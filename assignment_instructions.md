# NDTA 631 - Data Analysis And Visualization (Group Assignment)

## 📌 General Information
- **Module:** NDTA 631 - Data Analysis And Visualization
- **Group Size:** 6 to 7 students
- **Due Date:** 24 August 2026 (NO EXTENSIONS)
- **Total Marks:** 100

## 🎯 Project Objective
Build a complete data analysis and visualization pipeline. The project must use **at least two different South African datasets** to tell one clear story. 

**Dataset Constraints:**
- Sourced from [World Bank Open Data (ZAF)](https://data360.worldbank.org/en/search?country=ZAF).
- Must work together logically to present a cohesive narrative.
- **CRITICAL:** No two groups may use the same datasets. Verify the datasets chosen by other groups before starting. Repeating datasets incurs a **15% penalty**.

## 🛠️ Technical Requirements
- **Tools:** Python (Pandas, NumPy, Matplotlib, Seaborn) or Excel.
- **Database:** Build and query a database, then integrate it with Python/Excel.
- **Version Control:** Use Git.

## 📦 Deliverables Breakdown (100 Marks)

### 1. Data Preparation (15 marks)
- Load and clean real-world datasets.
- Handle missing values properly.
- Generate descriptive statistics and initial insights.

### 2. Numerical Analysis (20 marks)
- Use `NumPy` for numerical calculations.
- Reshape arrays and perform data operations.
- Clearly explain numerical findings and tables.

### 3. Visualization (20 marks)
- Create various plots (e.g., bar, scatter, box, histograms).
- Explain the trends and patterns revealed by the visualizations.
- Ensure clear use of colors, labels, and legends to help tell the story.

### 4. Database Integration (20 marks)
- Build a structured database.
- Write queries to extract, update, and delete records safely.
- Load database records into `Pandas` (or export to CSV). Include screenshots or schema diagrams as evidence.

### 5. Python/Excel Data Analysis (15 marks)
- Clean, transform, and structure the data.
- Apply conditional formatting (if Excel) or data manipulation (if Python).
- Create summary charts and compile findings.

### 6. Report & Demo (10 marks)
- **Report:** Write a 7 to 9-page actionable report (Submit as DOCX and PDF).
- **Contents:** Must include dataset details, methodologies used, clear visualizations, and conclusions.
- **Demo:** Present the project with a clear video demo or comprehensive screenshots (Video demo is highly recommended).
